# hadeerhanafy.com

Personal portfolio — Hadeer Hanafy, AI Ads Creator.

Static site. No build step: `index.html` plus `assets/`.

- `index.html` — the whole page (markup, styles, script)
- `assets/` — 3D character sprite sheet, portraits, film loops (`w*-loop.webp`) and films (`w*.mp4`)
- `vercel.json` — security headers and long-lived caching for `assets/`
